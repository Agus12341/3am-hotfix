# 3am-hotfix

An entry for make.fun's [3 AM Hotfix: The Funniest Commit Message](https://make.fun/bounty/u-yuki-kato-3-am-hotfix-the-funniest-commit-message-e9f60106) bounty.

`main.py` writes one line to `/output/entry.txt`, with no trailing newline:

```
fix(prod): remove the bug by removing the feature, the tests, and all evidence it ever shipped
```

The line is 94 characters, under the 179-character gate. The program
checks its own length before writing and creates `/output` if needed.
